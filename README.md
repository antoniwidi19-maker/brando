
# ORBITAL — Intelligence Beyond Earth

A futuristic space-themed landing page built with HTML, CSS, and JavaScript.

## Features

- Animated starfield canvas
- Futuristic orbital interface
- CSS-generated planet visualization
- Satellite animation
- Mouse movement interaction
- Scroll reveal animation
- Responsive mobile layout
- Mobile navigation menu
- Smooth scrolling
- No external JavaScript libraries

## Technologies

- HTML5
- CSS3
- JavaScript
- Canvas API

## Project Structure

```text
orbital/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Deploy with GitHub Pages

1. Create a GitHub repository.
2. Upload all project files.
3. Open repository Settings.
4. Go to Pages.
5. Select Deploy from a branch.
6. Select the main branch and root folder.
7. Save.
8. Wait for the website to deploy.
