Overview

BRANDO is a futuristic website experience built to explore the boundaries of modern web design. Combining dark aesthetics, cinematic visual effects, interactive elements, and smooth motion, BRANDO creates a digital environment inspired by deep space and next-generation technology.

The project focuses on delivering an immersive experience through lightweight web technologies without requiring a large framework.

Design Philosophy

- Minimalism — Clean layouts with intentional spacing.
- Futurism — Inspired by space exploration and advanced technology.
- Immersion — Motion, depth, lighting, and atmosphere.
- Interaction — Elements respond to user actions.
- Performance — Lightweight technologies and optimized animations.
- Adaptability — Designed for desktop and mobile screens.

Getting Started

1. Clone the repository

git clone https://github.com/antoniwidi19-maker/brando.git

2. Open the project folder

cd brando

3. Run the website

Open "index.html" directly in your browser.

For the best development experience, use a local server such as Visual Studio Code Live Server.

Deployment

BRANDO can be deployed using GitHub Pages.

1. Open your GitHub repository.
2. Navigate to Settings.
3. Open Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Select the "main" branch.
6. Select the "/root" directory.
7. Save the configuration.
8. Wait for GitHub Pages to publish your website.

Your website will be available at:

"https://antoniwidi19-maker.github.io/brando/"

Performance

The project uses lightweight browser-native technologies.

- No heavy frontend framework required
- Canvas-based star rendering
- CSS-based planetary effects
- Intersection Observer for scroll reveals
- Responsive assets and layouts
- Hardware-accelerated transforms where supported

Performance may vary depending on device capabilities and browser settings.

Accessibility

- Semantic HTML sections
